# 第 131 题 · Q131 · 把 class 改成 struct 就能摆脱 GC 吗

原题号：`Q41`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

性能分析发现大量独立的数据项对象。团队准备把含有 string 字段的数据项从 class 改为 struct，直接存入该结构体的数组；使用普通托管代码，不涉及 unsafe 自定义布局。

评审这次修改时，哪项准确描述改写后的对象图？

- A. 整个数组转为栈存储；元素改成值类型后，数组和字符串都脱离 GC 管理。
- B. 数组内联保存数据项的值；各元素的 string 字段仍保存指向字符串对象的引用。
- C. 数组仍只保存引用；每个 struct 元素都必须单独装箱，才能放入这个数组。
- D. 数组内联保存数据项及字符串字符；复制一个元素会同时复制字符串的字符内容。
