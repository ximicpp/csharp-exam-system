# 第 100 题 · Q100 · unsafe、指针与 GC

原题号：`Q220`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

同步本机函数只在调用期间借用托管数组的数据地址，返回后不再使用或保存指针。

在这个同步借用场景中，关于 unsafe 和指针，哪项描述正确？

- A. unsafe 允许指针操作；需要稳定托管对象地址时仍要按规则固定对象并限制指针使用期。
- B. 进入 unsafe 后所有托管对象都永久固定。
- C. unsafe 指针可以任意保存，指向的对象随后由 GC 保证不移动。
- D. unsafe 会把数组自动变成本机所有的内存。
