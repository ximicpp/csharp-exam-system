# 第 99 题 · Q99 · 源生成器与分析器的分工

原题号：`Q219`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

项目想在构建时为已有 partial 类型补充成员，并对命名规则给诊断。

要实现上述两个构建期目标，哪种分工符合 Roslyn 工具契约？

- A. 源生成器会直接删除或覆盖用户原来的类声明。
- B. 分析器必须在应用运行时才能发现编译问题。
- C. 只要加上 partial，成员就会自动生成而无需生成器实现。
- D. 源生成器添加参与编译的源码；分析器报告诊断，代码修复由相应修复工具提出。
