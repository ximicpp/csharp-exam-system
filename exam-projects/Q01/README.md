原题号：`Q121`。工程编号与考试显示号一致。

在 .NET 10 SDK 下，关于文件应用（file-based app）与项目应用，哪项描述正确？

- A. 顶级语句只能用于文件应用。
- B. 项目应用必须把所有类型写进 Program.cs。

- D. 文件应用像 Python 一样逐行解释，不需要编译。
