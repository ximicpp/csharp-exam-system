# 第 138 题 · Q138 · 对象存活与地址固定

原题号：`Q49`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

同步原生函数只在调用期间使用传入的托管 byte[] 数据地址。代码审查建议用 GC.KeepAlive(array) 代替包住原生调用的 fixed，以免 GC 移动数组。

哪个判断正确？假定原生函数返回后不会再保存或使用指针。

- A. 可以替代；只要对象仍然活着，压缩 GC 就不会移动它。
- B. 把数组设为 static 就等同于固定地址。
- C. 不能替代；KeepAlive 延长存活性，fixed 在其作用域内防止移动，两者解决不同问题。
- D. fixed 结束后数组会一直固定到它被回收，因此原生函数以后保存指针也安全。
