# 第 159 题 · Q159 · async void 应放在哪个边界

原题号：`Q37`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

异步保存操作没有业务返回值，同时被按钮事件和批处理调用；两种调用方都要观察保存失败。

框架的按钮事件委托必须返回 void，批处理需要 await 完整保存过程。哪种 API 设计符合这两个边界？

- A. 保存逻辑使用 async void，由每个调用点的外层 try/catch 捕获异步失败。
- B. 保存逻辑返回表示完整操作的 Task；void 事件处理器 await 它并在处理器内处理失败。
- C. 保存逻辑返回 Task，但启动实际异步写入后就返回 Task.CompletedTask。
- D. 保存逻辑使用 async void，批处理用 Task.Run(() => SaveAsync()) 等待保存完成。
