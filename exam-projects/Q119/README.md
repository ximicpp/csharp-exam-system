# 第 119 题 · Q119 · GC 与 IDisposable 的职责

原题号：`Q239`。工程编号与考试显示号一致。

业务对象持有需要释放的资源，并实现了 IDisposable。

关于自动内存管理和资源释放，哪项成立？

- A. 调用 Dispose 后该对象的托管内存立即释放。
- B. GC 管理托管内存；Dispose 仍需按所有权契约确定性调用，不能假定 GC 自动调用它。
- C. 实现 IDisposable 后，最后一个引用离开作用域就自动调用 Dispose。
- D. GC 一回收对象就必定先调用它的 Dispose。
