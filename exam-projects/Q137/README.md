# 第 137 题 · Q137 · GC 没有释放业务已结束的对象

原题号：`Q47`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

请求处理结束且局部变量已离开方法，但内存转储显示：静态字典 → RequestState → 大数组。字典本意是保存正在处理的请求，却从未删除已完成项。

哪个诊断和修复方向最准确？

- A. GC 不会分析字典内部引用；给 RequestState 添加终结器即可让数组回收。
- B. 存在引用环时 C# 的 GC 就无法回收；把 RequestState 改成 struct 即可修复。
- C. 让处理方法的局部变量设为 null，然后在每个请求后调用 GC.Collect()。
- D. 静态字典构成强保留链；按业务生命周期移除条目，并检查是否还有其他根。
