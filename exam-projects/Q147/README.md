# 第 147 题 · Q147 · public const 的发布边界

原题号：`Q87`。工程编号与考试显示号一致。

题目项目使用 .NET 11 / C# 14，启用 nullable 与隐式 using；必要的额外 using 和入口在本题源码中提供。编译环境或配置另有指定时，以题干为准。

库 v1 发布 public const int Limit = 10；客户端编译后，部署二进制兼容的 v2 将该常量改为 20。客户端使用该常量构造实参，未重新编译。

对于这个已编译的普通 C# 客户端，替换库后，哪项准确描述常量的取值与更新方式？

- A. 只要替换库，所有客户端就必定使用 20。
- B. const 与 static readonly 在客户端的取值机制完全相同。
- C. 旧客户端使用编译时嵌入的 10；要采用 20，需重新编译客户端。若希望以后随库更新取值，可改用运行时读取的 API。
- D. 运行时会因常量值变化而拒绝加载库。
